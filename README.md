# PyCalc

Welcome to **PyCalc**!\
A simple, command-line Python program that started as a basic calculator but has grown into a collection of small tools in one place.

---

## Why I Made This

PyCalc began as a calculator project, but I realised I didn’t want to create four separate small Python projects for each tool. Instead, I combined them into a single project—PyCalc—which now includes:

- A basic calculator
- A weight conversion program
- A temperature conversion program
- A compound interest calculator

This approach allowed me to:

- Practice core Python skills in a hands‑on way
- Explore writing clean, modular code
- Learn how to structure functionality using functions
- Understand user input handling and error management
- Consolidate multiple small Python tools into one cohesive application

---

## What PyCalc Does

PyCalc provides four main features:

1. **Calculator** – Perform addition, subtraction, multiplication, and division.
2. **Weight Conversion** – Convert between kilograms and pounds/ounces.
3. **Temperature Conversion** – Convert between Celsius and Fahrenheit.
4. **Compound Interest Calculator** – Calculate future value based on principal, rate, and time.

All of these are accessible via a simple menu in the terminal.

---

## Key Python Concepts Practiced

- **Functions:** Each feature and operation is implemented as a function for modularity.
- **Variables:** Storing and updating user inputs and results.
- **Arithmetic Operators:** Using `+`, `-`, `*`, `/` and exponentiation for calculations.
- **User Input:** Reading from the terminal with `input()` and converting to numbers.
- **Error Handling:** Using `try`/`except` to catch invalid inputs and prevent crashes.
- **Modularity:** Organizing code so that each tool is easy to understand and maintain.

---

## Recent Improvements

- **Refactored to use functions instead of long **``** chains**, making the code cleaner and easier to expand.
- **Added multiple tools** beyond just a calculator.
- **Centralized input validation** to avoid repetitive code.

## How to Run

1. Ensure you have [Python](https://python.org) installed (version 3.6 or higher).
2. Clone or download this repository:
   ```bash
   git clone https://github.com/your-username/pycalc.git
   cd pycalc
   ```
3. Run PyCalc:
   ```bash
   python calculator.py
   ```
4. Follow the on-screen menu to select the tool you want to use.
